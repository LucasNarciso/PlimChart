# Guia de Contribuição para PlimChart

Agradecemos o seu interesse em ajudar a melhorar este projeto! Para manter a clareza legal, o processo de contribuição é focado em correções de bugs e pequenas melhorias.

## 1. Princípio Legal da Contribuição

Este projeto opera sob **Direitos Reservados (All Rights Reserved)**. Isso significa que o código fonte não pode ser distribuído.

**Ao enviar um Pull Request (PR), você concorda com o seguinte:**

1.  Você confirma que é o autor original do código que está enviando.
2.  Você concede uma licença irrevogável ao mantenedor do projeto (o autor) para incorporar sua contribuição ao código principal.
3.  Você entende que a contribuição será integrada ao projeto sob a mesma condição de **Direitos Reservados**, e o ato de contribuir não lhe confere permissão para distribuir o projeto completo.

Se você não concorda com estes termos, por favor, limite-se a reportar o bug como uma "Issue" (veja o item 2).

## 2. Reportando Bugs (Issues)

A melhor forma de nos ajudar é abrindo uma *issue* no GitHub com o máximo de detalhes possível, incluindo:

* Passos exatos para reproduzir o bug.
* Comportamento esperado vs. Comportamento atual.
* Versão do software e sistema operacional utilizados.

## 3. Enviando Correções de Código (Pull Requests)

Se você deseja enviar o código para corrigir o problema:

1.  **Faça um Fork** do repositório.
2.  **Crie um Branch** para a sua correção (ex: `fix/nome-do-bug`).
3.  **Faça suas alterações** e certifique-se de que o código passa por todos os testes (se houver).
4.  **Crie um Pull Request (PR)** para a branch principal (`main` ou `master`).

O seu PR deve ser pequeno, focado em uma única correção de bug e a descrição deve referenciar a *issue* correspondente.
